# Bundled fonts

Latin normal faces from `@fontsource/inter` 5.3.0 (400/500/600/700) and
`@fontsource/jetbrains-mono` 5.3.0 (400/500/700), matching `src/index.css`.
NSH 0.6.0 requires imported font assets inside the app directory, so these
files are copied from the root dependencies. Their OFL licenses are included.
