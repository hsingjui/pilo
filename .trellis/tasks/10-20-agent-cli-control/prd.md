# Pilo 内置 Agent CLI 自控

状态：in_progress。用户已明确要求实现，产品代码已接入；测试、构建和真实交互验证仍待明确授权。

## 目标与价值

让 Pilo 内置 Agent 通过 CLI 查询、修改全部可编辑设置，查询连接和项目，并向指定连接添加已有项目。Local、WSL、SSH 均可发起和接受跨连接管理，避免用户手动操作设置页面。

## 已确认的产品选择

- 优先支持 Pilo 内置 Agent，采用 CLI 方向。
- 完整支持全部设置，不缩减为主题演示版。
- 不增加自控开关、用户授权流程或逐项确认；由程序自动处理连接身份。
- 桌面与 WebUI 的通用偏好统一，不引入设备覆盖层。
- 允许跨 Local、WSL、SSH 管理配置及添加项目。

## 需求

R1. CLI 入口：建议复用 `pilo-server` 增加 `ctl` 模式，保持当前默认 Server、版本、指纹行为兼容。不新建独立 CLI 工程或第二个常驻管理服务。此技术选择随最终方案确认。

R2. 全部配置：建立可编辑设置清单与类型、作用域、约束、secret、平台能力描述；每项对应真实读写、保存或重置业务。覆盖：
- 主题模式、主题系列、自定义 CSS、自定义主题保存与移除。
- 语言、发送方式、消息显示与折叠、开发者模式、应用内快捷键、界面/阅读/代码/终端字体字号及重置。
- 插件通知和系统通知开关。
- 桌面开机启动、关闭窗口行为、全局快捷键。
- Local/WSL/SSH 配置、SSH 认证配置与凭据安全写入。
- 项目模型 Scope、连接命名模型、下一步预测、提示词增强、缓存保活。
- 远程访问开关、端口、地址等现有可编辑配置。

R3. 连接和项目：查询全部连接、项目；新增/保存连接配置；向指定连接添加已有目录。跨连接写操作显式给出目标连接或项目标识，路径按目标环境解释。不自动创建目录或同步远程源码。

R4. 共享偏好：Host 为通用偏好事实来源，桌面和 WebUI 同步；客户端仅作启动缓存和旧数据迁移来源。连接与项目设置保留作用域，桌面原生行为仍只作用于 Host。插件通知偏好保持桌面专属，不为 WebUI 新增开关。

R5. 运行模式：覆盖 Local、WSL、远端 Pi 加 SSH、本地 Pi 加 SSH 工作区；普通和临时交互会话均可用。内部探测/预测等后台模型任务不额外暴露自控能力。无需用户手动安装 CLI 或复制 token。

R6. 信任和隐私：不增加用户审批，但自动绑定目标实例与运行中会话，拒绝错误或失效上下文。不公开无身份校验的管理接口，不取消原有 WebUI 配对、SSH 认证或系统授权。凭据支持标准输入写入和现有系统凭据库保存，普通查询、日志、事件和命令参数不暴露秘密。

R7. 一致性：界面和 CLI 复用业务流程，提交后由 Runtime 发布配置、连接、项目变更，桌面和 WebUI 均更新。通用偏好字段级修改、持久化及重连恢复，不允许旧客户端缓存覆盖新值；同时保证移动端可用。

R8. 结果与生命周期：JSON 输出、非零失败退出码、stderr 诊断；返回实际提交值、目标和系统交互/重连状态。共享偏好带 revision。Host 不在线明确失败，不偷偷启动 Server。写请求不自动重放；重复添加项目保持稳定 ID。会话退出与连接失效可清理上下文、监听及待响应请求。

## 不在范围

- MCP、外部 Agent 接入、鼠标键盘自动化、独立 CLI 产品。
- 项目/会话删除、任意文件删除、完整会话管理。集合型设置的条目移除仍属于 R2。
- 打开日志目录、跳转链接、安装更新、卸载等非配置按钮。
- 任意 Tauri invoke、任意数据库写、设置 UI 未管理的任意 Pi 文件修改、系统秘密读取。
- 为 WebUI 复制桌面管理页面或伪造桌面系统能力。

## 验收标准

- AC1（R1/R8）：旧启动方式兼容，ctl 正常返回/退出，无额外常驻进程；Host 不在线有明确错误。
- AC2（R2/R6）：全部可编辑项均有清单和实际 setter/重置；未知 key、非法值被拒绝，秘密不回显。
- AC3（R3/R5）：四种运行模式均能跨连接管理配置、添加项目；混合 SSH 无手工部署步骤。
- AC4（R4/R7）：桌面/WebUI 偏好在线同步、重启持久化、离线重连恢复；旧缓存不覆盖 Host。
- AC5（R4/R8）：桌面系统设置真实生效，系统拒绝或平台不支持返回真实原因，不伪报成功。
- AC6（R6）：内置会话默认可用，无额外授权或确认；无效上下文和错误实例被拒绝。
- AC7（R7/R8）：CLI 添加项目保留检视、存储、打开生命周期与 UI 更新；失败结果明确，不遗留无界队列或资源。
- AC8（R5/R6）：会话/Server/Host 退出后上下文失效；多实例以及开发版与正式版不串用。

## 风险与最终确认

完整设置覆盖涉及客户端偏好迁移、Host 原生系统能力和跨环境回传，不是只增加命令参数。旧偏好迁移建议以既有 Host 数据优先，首次导入桌面数据；技术细节见 design.md。

用户的范围与体验选择已收敛，无阻塞产品问题。用户已通过“来实现一下cli的自控吧”批准实施，任务已启动。测试代码变更、测试与构建执行仍需明确请求。
